# Services

This folder contains core services such as Authorization, Storage, and Interceptor.

The `Services` facade provides access to various services such as `Authorization`, `Storage`, and `Interceptor` services. These services can be used to handle authorization, storage, and request/response interceptors for API calls.

- `client/`: Client-side services (Authorization, Storage).
- `interceptorService.ts`: Request/response interceptor management.

See also: [client/README.md](./client/README.md)
